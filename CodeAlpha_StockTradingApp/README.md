# Stock Trading App

## About the Project

A simple Stock Trading Platform developed using Java. It allows users to view available stocks, buy and sell shares, manage their portfolio, and track their available balance.

 Features

- Displays available stocks and their prices.
- Allows users to buy and sell stocks.
- Tracks purchased shares and quantities.
- Displays portfolio value and total assets.
- Saves and loads portfolio data using file handling.
- Validates stock transactions and quantities.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList and HashMap
- File Handling
- Conditional Statements
- Loops

## How to Run

1. Install JDK on your system.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Compile the program:

```bash
javac StockTradingApp.java
```

5. Run the program:

```bash
java StockTradingApp
```

## How to Use

1. Run the program.
2. Select an option from the menu.
3. View available market stocks.
4. Buy or sell shares by entering the stock symbol and quantity.
5. Check your portfolio and balance.
6. Save your portfolio before exiting.
