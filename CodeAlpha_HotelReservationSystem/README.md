# Hotel Reservation System 

## About the Project

A console-based Hotel Reservation System developed using Java. It allows users to search available rooms, book rooms, view booking details, and cancel reservations with automatic bill calculation.

## Features

- Search available hotel rooms.
- Choose room categories (Standard, Deluxe, Suite).
- Book rooms with check-in and check-out dates.
- Calculate total booking amount automatically.
- View booking details and booking ID.
- Cancel existing reservations.
- Save and load booking records using file handling.
- Check room availability based on booking dates.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- File Handling
- LocalDate and ChronoUnit
- Exception Handling

## How to Run

1. Install JDK on your system.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac HotelReservationSystem.java
```

5. Run the program:

```bash
java HotelReservationSystem
```

## How to Use

1. Run the application.
2. Search for available rooms.
3. Select a room category.
4. Enter customer details and booking dates.
5. Confirm the booking.
6. View or cancel reservations using the menu.
