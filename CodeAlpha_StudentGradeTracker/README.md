# Student Grade Tracker 

## About the Project

A console-based Student Grade Tracker developed using Java. It allows users to enter student names and marks, generate student performance reports, and calculate average, highest, and lowest marks.

## Features

- Enter the number of students.
- Store student names and marks.
- Display all student records.
- Calculate average marks.
- Identify the highest marks.
- Identify the lowest marks.
- Generate a student performance report.

## Technologies Used

- Java
- Scanner Class
- Arrays
- Loops
- Conditional Statements
- Arithmetic Operations

## How to Run

1. Install JDK on your system.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac StudentGradeTracker.java
```

5. Run the program:

```bash
java StudentGradeTracker
```

## How to Use

1. Run the application.
2. Enter the number of students.
3. Enter each student's name.
4. Enter the marks for each student.
5. View the student performance report.
6. Check the average, highest, and lowest marks.
